# SKILL: Custom Brand UI Clone
This skill forces the agent to mimic the structural layout of a reference site while applying the user's custom brand identity.

## Brand Identity Constraints (OVERRIDE SOURCE COLORS)
- **Primary Color:** [e.g., Deep Blue #1E3A8A]
- **Accent/Secondary Color:** [e.g., Orange #F97316]
- **Background Color:** [e.g., White #FFFFFF]

## Structural Source of Truth
- **Layout Reference:** Use the open `.htm` file and its accompanying assets folder.
- **Rules:** Copy the exact padding, grid/flex layouts, typography sizing hierarchies, and component placements from the source file. Completely ignore its original colors and inject our Brand Identity colors instead.
